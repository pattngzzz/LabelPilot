# LabelPilot 本地半自动标注工作台

## 启动

双击本目录的 `start.cmd`。启动窗口保持打开，浏览器会自动打开 `http://127.0.0.1:8765`。
关闭服务：在启动窗口按 `Ctrl+C`。服务仅监听本机，不开放局域网访问。

启动器优先使用 `LABELPILOT_PYTHON` 指定的解释器，其次检查 `D:\Miniconda3\envs\key_action_py311\python.exe`、项目内的 `.venv\Scripts\python.exe` 和 PATH 上的 Python。可在 PowerShell 中用 `$env:LABELPILOT_PYTHON='你的python.exe'` 切换到已有的 CUDA / Ultralytics 环境。换端口可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Port 8767`。

## 标注任务

打开左上角的「新建项目」，先选任务类型，再选择本机图片。任务类型随项目保存，已有项目默认采用目标检测。

| 任务 | 标注与预标注 | 数据导出 |
| --- | --- | --- |
| 目标检测 | R 绘制边界框，使用本地 YOLO 检测权重预标注 | YOLO、COCO、Labelme |
| 实例分割 | P 描轮廓，点选辅助提取实例轮廓，使用分割权重预标注 | YOLO 分割多边形、COCO、Labelme |
| 语义分割 | P 圈区域、B 画笔、X 橡皮，使用语义权重生成类别图 | 单通道 PNG 掩膜与 `dataset.yaml` |
| 手部姿态 | K 按顺序标注 21 点，可调整位置、跳点或标记遮挡，支持多只手 | YOLO Pose、COCO Keypoints |

语义掩膜以像素值保存类别，背景为 0，前景按项目类别顺序从 1 开始。后画的区域覆盖之前的类别，橡皮擦回背景。手部关键点的可见性为 0（未标注）、1（遮挡）、2（可见）。

各任务都可从已审核数据启动本地训练、下载权重，再用权重预标注。配置预标注权重时，任务、类别顺序和关键点结构应与项目匹配。语义分割训练使用支持 YOLO26 Semantic 的 Ultralytics 运行环境。逐框盲测对比和自动验收在目标检测项目中使用。

## 推荐流程

1. 选择批次或审核状态，点击图片。原有框及描述、属性、group_id 会保留。
2. 点击“模型预标注”，检查本地模型路径、置信度、IoU 和输入尺寸。模型 ID / 名称必须和项目逐项匹配。
3. 推理后选择“追加对象”或“替换当前对象”。这里只改变当前画布，尚未保存；替换可以撤销。追加不会自动去重，须检查重叠框。
4. 按 **R**，单击起点后松开，移动鼠标预览矩形，再单击对角终点完成框选，不需要长按拖动。框旁自动弹出标签窗口，默认聚焦确认按钮，按 **Q / Enter** 使用当前标签，也可点击已有标签；点击输入框输入自定义名称后，按 Enter / 点击“创建并使用”。输入框内的 q / Q 正常输入文字，不触发确认；确认后才加入当前标注。Esc 或“取消框选”可取消，不会新增对象。V 选择、拖动、调整框角或边；P 逐点画多边形，**Q / Enter** 完成。**A 上一张、D 下一张**，有修改会自动保存为草稿，翻页不会自动审核。右侧可以改标签、描述和难例。多边形可拖动顶点。
5. “保存草稿”独立保存修改；按 **E** 或点击“确认并下一张”会保存、将当前图片标记为已审核，再进入下一张，表示你已检查当前整张图片。长按 E 不会连续审核多张；输入标签或打开弹窗时不会触发。历史人工标注和模型结果不会自动变为“已审核”。零检测也不会自动成为负样本，空标注审核需要明确确认。
6. 导出时默认仅纳入已人工确认的图片。可选 YOLO 检测、Labelme / X-AnyLabeling、COCO；可自行设置训练 / 验证 / 测试集比例，默认 80% / 10% / 10%，也可取消划分。可选训练集数据增强，默认不启用。所有导出包含类别、来源及划分清单。

界面默认采用紧凑布局，优先给图片分配空间。按 **Tab** 或点击工具栏的“大画布”，可收起顶部和两侧面板，再按一次恢复；偏好会在本机浏览器保留。滚轮以鼠标位置为中心缩放，F 适应画布，空格拖拽平移。

按 **R** 进入矩形框模式后，十字光标的上下左右各有一条延伸至画布边缘的虚线，随鼠标移动，辅助对齐框选位置；图片缩放 / 平移不改变辅助线与光标的对齐。鼠标离开画布、切换工具、打开框选标签窗口或按住空格平移时隐藏。辅助线仅用于界面显示，不写入标注或导出数据。

### 待审核队列

在左侧点击“待审核队列”，按优先级查看导入标注、模型候选和草稿。队列先呈现未确认空图，其次是标有难例的图片，再按最低对象置信度排列低于 50% 的候选。状态下拉菜单可以单独查看其中一种原因。关键词和批次筛选同时生效。

按 **E** 审核当前图片并进入下一张。确认空图仍需应答确认提示。按 **A / D** 时仍按原流程翻页并暂存草稿。审核通过或跳过的图片离开待审核队列。

### 自定义标签

在右侧“输入自定义标签”中输入原始名称，按 Enter 或点击“+”。新增标签会成为当前绘制标签；如果已经选中对象，也会把该对象改为此标签，随后需要保存。重复输入已有名称只会选用已有标签，不会产生重复 ID。

标签名称在画布、列表、选择框和导出中原样保留，不自动翻译成中文。新标签追加在类别表末尾，不重排原有 ID。首次添加时，工具将当前有序类别独立保存到自身 `projects.json`，并记录原类别映射路径，不改动源 `class_map.json`。

追加标签后原基线仍可为已有类别预标注，但不会自动识别新增类别。新增类别需要人工标注或后续训练支持；模型原有类别 ID / 名称仍须与项目对应，错序和改名会被拒绝。

### 选择和切换模型

在模型设置中点击“选择文件”，通过本机文件浏览窗口进入文件夹并点击 `.pt` 权重；也可点击“选择文件夹”，进入目标目录后点击“选择此文件夹并查找模型”，从包含子文件夹的候选结果中明确选择一个模型。不再需要手动复制完整路径，仍保留直接输入路径的方式。

支持磁盘切换、输入文件夹路径、上一级目录和中文路径。浏览只返回文件名、路径和大小，不上传、复制、加载或执行权重；取消不会改变模型。扫描跳过链接 / 联接目录，最多检查 20,000 个目录项、列出 200 个模型，搜索预算为 5 秒；遇到权限或数量限制会提示结果可能不完整，应缩小目录后继续查找。

选择后路径显示为“尚未保存配置”，点击“保存模型配置”或发起预标注后生效。下次推理按新路径重新加载模型并校验类别；单纯切换配置不改动当前标注。存在运行中或等待中的模型任务时，先等待结束或取消任务，再切换权重。只选择可信的本地 Ultralytics `.pt` 检测权重，文件后缀本身不能证明来源可信或类别兼容。

## 批量预标注

左侧星形模型按钮进入设置，指定当前批次 / 搜索范围和数量上限，点击“批量预标注”。只处理**未开始**图片，不覆盖人工标注、历史预标注或草稿。状态筛选不会扩大范围，也不会改变只处理未开始图片的保护。

任务在后台串行处理；界面可继续标注其他图片。可以取消，当前推理结束后停止。重启后未完成任务记为中断；重新启动批量任务时会跳过已保存结果，不自动伪造完成或审核状态。

## 提高标注效率

- **逐框快审。** 在画布工具栏选择“逐框快审”。用 `[` / `]` 切换并放大对象，Enter 确认当前框并跳到下一框。用数字键改类、Del 删除。最后回全图检查，再按 E 审核整张。
- **连续帧。** 选中矩形框后点击“带所选框到下一张”，将框作为草稿追加到同源下一张。插值时先“设为起点”，再到最后一帧仍可见该目标的图片上选中对应框，点击“末帧预览插值”，核对后写入草稿。插值只覆盖两端之间的已有帧，已审核或已有匹配框的图片会跳过。帧序可由同一来源组内唯一的整数 `frame_index` 提供，也可由同文件夹、同前缀文件名末尾的数字确定。无来源组时，同一文件夹按当前序列处理。
- **四点画框。** 依提示点击上、下、左、右边缘，再用既有标签选择器确认。适合边缘位置明确的目标。
- **点选辅助。** 在目标上添加前景点，按需标记要排除的背景，预览后点击“采用候选框”。它在本机使用 OpenCV GrabCut 生成外接矩形。点位及候选在确认前可清空或按 Esc 取消。
- **相似筛图。** 左侧“相似筛图”在所选批次的未标注图中查找视觉近似候选。可先选每组推荐图，再勾回有差异的图。筛选结果作为可恢复的队列视图保存，批量预标注在此视图中只处理保留图。
- **按疑点复核。** 左侧“疑点复核”用项目本地检测模型扫描已标注图片。候选置信度默认 0.60。疑点队列逐图显示原标注及预测提示框，支持继续编辑或确认本图已核对。疑点是给人工核查的线索，模型扫描本身只写复核记录。
- **跟踪辅助。** 在“连续帧”模式选框后点击“跟踪选中框”。OpenCV 根据画面特征移动边框，遇到失跟、遮挡疑点或出画边缘时会停在待修帧。预览后写入可靠帧的草稿，可跳到待修帧重设起点。跟踪需要明确帧序及目标纹理。
- **自动保存和断点续标。** 可在画布下方开关自动草稿保存。停下编辑约两秒即保存草稿。重新打开时恢复上次的筛选、图片、对象和缩放，浏览器在后台预取队列下一张图。

## 自动流程

打开顶部“自动流程”。设置保存在本机，按项目生效。勾选的自动流程在 LabelPilot 本地服务运行时执行。

- **收图与审核。** 可立即处理新批次，也可开启目录监控。监控范围是本项目原图目录或其中一个子目录。流程等待文件稳定后验证图片，登记独立批次，跳过已登记和字节相同的副本，扫描相似组后调用本地模型预标注。“相似组优先预标推荐图”可把其余成员暂缓在普通队列中，之后仍可手工纳入。流程保留已成功写入的草稿和分流记录，重试继续处理失败或尚未完成的项目。
- **智能审核分流。** 可单独对当前批次的候选标注运行。空图、稀有类别、低置信和可选的第二模型分歧优先排列。普通图可按来源组抽样，无来源组时按原图所在目录分层。两种队列仍使用人工审核和逐框快审。
- **训练与验收。** 选一个固定盲测集，设定最少可训练图片、每个验收类最少带框图片，以及各类的召回率下限和误检上限。工作流按原有规则清洗并排除盲测数据，生成训练快照，训练后用同一盲测集比较冻结的基线和候选权重。可主动启动，也可开启达标后自动开始。各类别通过后，运行记录会出现“确认启用候选模型”。已完成的子步骤可在重试时复用，未完成的训练从该训练步骤重新开始。

## 接入新项目与后续模型

点击左上角“＋ 选择图片”，在新项目窗口中点击“选择图片文件”或“选择文件夹”，浏览本机磁盘、进入目录后确认，不需要手动复制地址；仍保留输入完整目录路径的方式。图片文件支持同文件夹多选（JPG / JPEG / PNG / BMP / WEBP / TIF / TIFF），只导入明确选中的图片，重新扫描或重启不会把同目录其他图片加入该项目；切换浏览目录会清空尚未确认的临时勾选，取消不会改变已有选择。文件夹模式递归读取其中及子目录的图片，也可点击“改为整个文件夹”退出文件列表模式。选择后填写项目名称和有序类别，再点击“建立项目”；新项目与原项目独立，原图只读引用，不上传、不复制、不覆盖已有标注。

还可填写 Labelme 标注目录、预标注目录、有序类别和可信本地 `.pt` 检测模型。华聚式项目可以额外指定任务清单；指定图片文件与任务清单不能同时使用。浏览列表跳过链接 / 联接，最多读取 20,000 个目录项，达到上限或遇权限问题会提示列表可能不完整；请选择更具体的文件夹。文件列表项目最多选择 10,000 张图片，所选文件必须在项目图片目录内，缺失或非法路径会拒绝导入，不会自动改为导入整个目录。

类别输入顺序就是模型类别 ID，不能为了显示方便随意排序。支持 `classes.txt` 或带 `names` 列表 / ID 字典的 JSON。模型可以覆盖完整标签表，或覆盖其顺序完全一致的前缀（末尾为人工新增标签）。只有图片目录和类别是必填项。训练完成后，可在模型设置中切换权重，也可从训练记录将产物设为项目预标注模型。

新增原图或外部标注后，点击图片队列右上角“↻”重新扫描；本工具已保存的独立版本不会覆盖回源文件。存在重名图片且标注对应关系不唯一时会拒绝自动匹配，需拆分目录 / 项目或使用唯一文件名。

## 数据质量预检与导出

打开“导出数据集”即可预览所选批次和审核范围内的图片、标注对象、已确认空图及各集合的类别分布。预检会提示训练集缺少的类别、已知来源组跨集以及 YOLO 与多边形的格式冲突。它读取已保存的标注，生成 ZIP 时再核验原图指纹和尺寸。如果另一窗口更新了标注，生成前会刷新预检，确认新结果后再点击导出。

勾选“划分训练、验证和测试集”后可以设置比例和随机种子。三个百分比之和必须为 100%，训练集比例须大于 0。验证和测试集可以设为 0。相同图片、分组、比例和种子可以复现划分。预检显示最终分配张数。

- **按任务清单来源组**会将同一 `source_group` 的图片放入同一个集合。有来源组的项目默认使用此方式。所选图片须全部有来源组，且组数至少等于启用的集合数。
- **按原图文件夹**会将同一原图文件夹里的照片放入同一个集合。可用于按视频或拍摄批次分目录的项目。实际比例受每组张数影响，同源图片分散在不同目录时仍有可能跨集。
- **按图片随机**按张数分配，适用于独立拍摄的图片。连续帧或重复图片可能跨集。类别覆盖请查看预检结果。

选择格式后生成 ZIP。`export_manifest.json` 记录划分方式、比例、种子、实际张数和每张图片的集合。按组划分时还会记录具体分组，取消划分时保留平铺目录。

- **YOLO** 将图片和标签写入 `images/train|val|test`、`labels/train|val|test`，并生成 `dataset.yaml`。用于 Ultralytics 训练时需提供图片和非空验证集。
- **Labelme / X-AnyLabeling** 将逐图 JSON 写入 `annotations/train|val|test`，保留对象属性，并将普通矩形导出为两个对角点。`imagePath` 指向对应的图片副本。
- **COCO** 按启用的集合生成 `annotations/train.json`、`annotations/val.json`、`annotations/test.json`，其中 `file_name` 相对于解压后的数据集根目录。

## 一键清洗

顶部的“一键清洗”立即扫描当前批次的已审核图片，预览保留张数和排除原因。图片文件不可用或已变更、标注结构异常的项会单独列出。完全相同的图片按文件 SHA-256 识别。标注一致的重复组保留一张，标注冲突的重复组暂时排除全部副本，可从预检示例打开对应图片核对。

默认生成保留对象属性的 Labelme ZIP。可切换格式或开启分组划分。真实负样本仍可纳入，清洗结果和完整排除记录写到独立的导出包及 `export_manifest.json`，源文件和审核历史继续以只读方式引用。清洗依据精确重复和可校验的结构问题，近似帧及语义错误需要人工检查。

## 一键训练

顶部的“一键训练”会用所选批次的已审核检测框创建清洗版数据，并按 80% / 20% 划分训练集和验证集。两个集合都需要有带框图片。项目有任务清单来源组时默认按组划分，也可以按原图文件夹划分。共享已知来源组的训练集和验证集会被拒绝。

可微调从项目模型设置选中的可信本地 `.pt` 权重，或使用 Ultralytics 自带的 YOLO11n 配置从零训练。默认自动选择设备，也可以显式选 CPU 或 CUDA。训练尺寸、轮数、批大小和随机种子在同一个窗口配置。训练依赖项与本地推理相同，CPU 或 CUDA 取决于 `start.cmd` 使用的 PyTorch 环境。

点击“开始训练”后，本地后台任务复制并校验图片、保存数据清单、启动 YOLO。训练记录提供轮数进度、验证集 mAP、召回率、精确率、日志和停止按钮。成功后可以下载 `best.pt`，或者显式设为项目预标注模型。每次运行的快照、日志和权重保存在 `data/training/<任务 ID>/`，关闭浏览器后可通过同一服务继续查看。退出本地服务会停止其训练进程，未完成的记录会保留。

一键训练当前使用目标检测框。需要保留多边形的项目可用 COCO 或 Labelme 导出。

## 固定盲测集与模型对比

1. 打开顶部的“模型对比”，点击“冻结新盲测集”。填写名称，选择已审核图片所在批次、冻结比例和种子。若有任务清单来源组，默认按组抽取。已明确确认的空图也会纳入抽样。设为 100% 可冻结所选批次中的全部合格图片。
2. 选择盲测集，以及旧版和新版可信本地 YOLO 检测权重（`.pt`）。可选项目现用权重、近期本地训练产物，或浏览本机文件。点击“一键对比”，两版模型使用完全相同的图片、真值和推理设置。
3. 查看各类别的召回率、漏检数和误检数，或下载 JSON 报告。默认置信度为 0.25、匹配 IoU 为 0.50。预测框按置信度降序匹配同类真值，每个真值最多匹配一次。未配对的真值计为漏检，未配对的预测计为误检。无真值的类别用「—」显示召回率，空图上的检测也计入误检。
4. 点击漏检或误检数字查看对应的冻结图片。旧版和新版两栏都叠加人工标注和各自的预测框，可切换类别，或筛选“新版新增漏检”和“新版修复漏检”。筛选比较同一张图上的同一个真值框，因此同一张图可以同时包含新增和修复的漏检。早期记录可使用同一盲测集重新对比以生成逐图明细。

快照位于 `data/blindsets/<盲测集 ID>/`，保存冻结时的图片、矩形标注、类别和指纹。后续修改原始项目不会更改该快照。冻结完成后的本地训练会排除盲测图片、相同 SHA-256 的副本及已知同源组；按目录冻结同时预留相应目录。已有本地训练产物如有对应数据清单，报告会显示已知重叠。对外部权重，报告会标记训练数据无法核实。

## 数据保存与保护

- 图片、任务清单、原生标注和旧预标注只读。新修改保存在本目录 `data\workbench.sqlite3`，包含每次保存的完整版本以及首次导入快照。
- 原图 SHA-256 / 尺寸校验、原生标注首次保存前指纹校验和版本冲突检测，防止错误套图或多窗口覆盖。
- 导出 ZIP 保存在本目录 `exports`。模型设置、任务状态、推理与绘图库缓存均放在本工具目录中。
- 建议关闭服务后备份整个 `data` 目录和 `projects.json`。不要仅在运行中复制一个 SQLite 主文件而漏掉 WAL 文件。
- 没有账户和云同步；本地会话令牌、同源校验和 Host 限制用于防止外部网页操作本地服务。不应自行把端口暴露到公网。
- PyTorch 权重可能执行反序列化代码，只加载你信任的模型；不会按模型名自动下载权重。

## 当前边界

支持检测框、多边形和基于 OpenCV 的点选候选框。YOLO 检测导出遇到多边形会报错，不会悄悄转成外接框；多边形请选择 COCO / Labelme。含 EXIF 旋转的原图会阻止编辑，需先建立方向归一化的独立副本。

真实人工标注准确性、模型独立泛化指标、长期批量运行稳定性：`NOT_PROVEN`，需要真实人工审核 / 独立验证集 / 长时间运行证据。预标注减少多少人工时间也尚未测量。

## 导出时数据增强

在导出窗口的“导出时数据增强”选择方案，设置每张训练图片**每种方案额外生成 1–3 张**及增强随机种子。默认“不增强”，原有导出行为不变。四种方案均基于已有 Pillow，不增加生产依赖：

| 方案 | 处理 | 适用与限制 |
| --- | --- | --- |
| 轻量通用（推荐） | 亮度 0.85–1.15，饱和度、对比度 0.90–1.10 | 保守起步，不改变几何位置 |
| 光照变化 | 亮度 0.65–1.35，饱和度、对比度 0.80–1.20 | 模拟明暗和色彩变化，不做翻转 |
| 画质扰动 | 亮度、对比度 0.90–1.10，模糊半径 0.3–0.8 像素，JPEG 质量 65–85 | 模拟轻微模糊、压缩；小目标、铭牌细字谨慎选用 |
| 水平翻转 + 轻量变化 | 左右镜像并同步框 / 多边形坐标，叠加轻量变化 | 仅适合左右无关类别，文字、左右方向有语义时不要使用 |

选择“全部方案（分别生成）”会让上述四种方案各自从原图独立生成，不会把四种处理连续叠在同一副本上。数量按**每方案**计算：设为 1 / 2 / 3 时，每张训练原图分别增加 4 / 8 / 12 张，保留原图后共 5 / 9 / 13 张；界面实时显示总数。建议全部方案先设为 1，文字、方向类别或特别小的目标不宜直接用全部方案。

增强随机种子决定亮度、对比度、模糊等随机参数。相同原图、种子、方案和软件环境可复现相同副本；换种子得到另一组变化，不表示增强更强或更好。默认 42 没有特殊质量含义。它独立于数据集划分种子，单独改变增强种子不会改变原图的训练 / 验证 / 测试归属；全部方案中的每种结果与同种子下单独选择该方案一致。

增强必须勾选“只导出已人工确认”和“包含原始图片副本”，并启用数据集划分；只要训练集时可设为 100 / 0 / 0。先划分原图，再仅对 `train` 生成副本，`val` / `test` 不增强。同一原图及其增强副本不会跨集，但原来不同文件之间的同源 / 重复问题仍需检查。比例作用于原图；例如原图分配 80 / 10 / 10 张，每张训练图额外 1 张，则最终 160 / 10 / 10 张，不会重新划分增强结果。

始终保留原图副本；新增图片为独立 JPEG，透明图片在增强副本中合成到白底。YOLO 检测、Labelme、COCO 均生成对应标注，类别名称和 ID 不变；YOLO 遇多边形仍拒绝导出。Labelme 保留对象属性，同时将增强副本标记为未单独人工审核，不冒充原始审核结果。写入 ZIP 前会逐张核验原图 / 增强图 SHA-256 与尺寸、对象数量、类别、属性和坐标；无几何变化的方案要求标注点完全一致，水平翻转则逐点核对变换后的精确坐标。然后回读 YOLO / Labelme / COCO 导出内容，检查对象数量、坐标及图片配对，并检查 ZIP 路径无冲突。任一检查失败就中止并删除不完整 ZIP，不会静默丢框或自动修框。导出清单记录源图片 ID / SHA-256 / 版本、方案、操作参数、随机种子、Pillow 版本和增强后图片 SHA-256，并记录校验通过的图片 / 标注对象数量；同一源文件、参数和环境可复现。每包原图不超过 10000 张，含增强最多 20000 张。

增强只写导出包，不新增数据库标注、不改变审核状态、不写源文件。建议从轻量方案、额外 1 张开始；增强不是新采集数据，也不代表改善泛化，实际训练收益为 `NOT_PROVEN`，需保持独立验证 / 测试集做对比。训练阶段若还启用在线增强，应避免叠加过强。

## 开发验证

```powershell
$py = 'D:\Miniconda3\envs\key_action_py311\python.exe'
$temp = Join-Path $env:TEMP ('labelpilot-tests-' + [guid]::NewGuid().ToString('N'))

$env:LABELPILOT_PYTHON = $py
```

测试依赖是已有的 pytest / httpx，没有安装新的生产依赖。当前测试环境的 Starlette TestClient 会提示 httpx 兼容弃用警告，但测试通过；为避免影响原有环境，未升级该依赖。
